# 打砖块 · 传说版

纯 HTML5 Canvas 打砖块游戏，单文件、零依赖、零构建，桌面与手机都能玩。

🎮 **[在线游玩](https://YOUR_USERNAME.github.io/breakout-game/)**

## 玩法

| 按键 | 作用 |
|---|---|
| `← →` / `A D` / 鼠标 / 触屏拖动 | 移动挡板 |
| 空格 / 点击 / 触屏轻点 | 发射小球 |
| `Z` | 发射激光（需激光道具） |
| `X` | 释放终极爆裂（能量满） |
| `C` | 合成道具（同时持有两个可合成道具时） |
| `P` | 暂停 |
| `M` | 静音 |

手机端有屏幕按钮，也可直接触屏拖动挡板。

## 特性

- **14 种道具**：加长挡板、三球分裂、激光炮、火球穿砖、黏性挡板、额外生命、减速、黄金砖、磁吸挡板、炸弹球、复制道具，以及缩小 / 加速 / 倒转三种陷阱
- **道具合成**：`激光+火球 → 过载激光`、`加长+黏性 → 巨爪挡板`、`分裂+炸弹 → 炸弹风暴`、`减速+黄金 → 黄金雨`
- **10 种砖块**：普通、多层（带裂纹）、钢铁、突破、黄金、弹簧（加速）、传送门（瞬移）、磁吸（吸球）、再生（倒计时复原）、Boss 核心
- **Boss 战**：每 5 关一个，会移动并发射弹幕，弹幕可用球击落
- **随机事件**：流星雨、零重力、黄金狂热、冰冻砖
- **连击与能量**：连击提高分数倍率并充能，能量满释放大招
- **8 项成就** + 最高分本地存档（带版本迁移）
- **无尽模式**

## 技术要点

- 子步进碰撞物理：按速度自动细分物理子步，高速球不会穿砖
- 固定步长主循环（120 Hz）+ 掉帧保护，切后台自动暂停
- `devicePixelRatio` 适配高分屏，画面不发虚
- Web Audio 合成音效，带失败保护（音频被拦截时不报错）
- 纯前端，无任何依赖与构建步骤

## 本地运行

直接双击 `docs/index.html`，或：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/docs/index.html
```

## 部署

仓库启用了 GitHub Pages，源为 `docs/` 目录。修改 `docs/index.html` 后推送到 `main` 即自动更新。
